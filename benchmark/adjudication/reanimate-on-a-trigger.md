# Adjudication: `reanimate-on-a-trigger`

Decide, for each card below, whether it satisfies the QUESTION.
Judge the card on its own text. There is no query here and you do not know which search returned it — that is deliberate.

## Question

> permanents that pull a creature out of my graveyard onto the battlefield when something happens

**What makes it tricky:** Requires binding a trigger to a graveyard-to-battlefield move; graveyard-to-hand cards like Raise Dead share almost all their vocabulary but land the card in the wrong zone.

**Cards already accepted as satisfying it** (for a consistent reading, not as a pattern to match): Sun Titan, Karmic Guide, Meren of Clan Nel Toth

**Cards already rejected**: Raise Dead

## Answer format

Write JSON to `verdicts/reanimate-on-a-trigger.json`: an object mapping each card name to `"present"`, `"absent"` or `"unclear"`.

- `present` — it clearly satisfies the question.
- `absent`  — it clearly does not.
- `unclear` — the question wording genuinely does not decide it. Use this freely; a forced call is worse than no call.

Every one of the cards listed must appear exactly once.
