## Question

> o:'sacrifice an artifact' as an activation cost, not an effect

**What makes it tricky:** The exact same words appear as a cost (before the colon) and as an instruction in an effect ('sacrifice an artifact: ...' vs 'you may sacrifice an artifact'), and text search cannot see the colon boundary.

**Author's notes:** Deliberately phrased in Scryfall-ese to vary register. Good probe of whether the system models cost-vs-effect position.

**Cards already accepted as satisfying it** (for a consistent reading, not as a pattern to match): Arcbound Ravager, Atog, Krark-Clan Ironworks

**Cards already rejected**: Shatter

## Answer format

Write JSON to `verdicts/sacrifice-artifact-as-cost.json`: an object mapping each card name to `"present"`, `"absent"` or `"unclear"`.

- `present` — it clearly satisfies the question.
- `absent`  — it clearly does not.
- `unclear` — the question wording genuinely does not decide it. Use this freely; a forced call is worse than no call.

Every one of the cards listed must appear exactly once.
