# Adjudication: `landfall-payoffs`

Decide, for each card below, whether it satisfies the QUESTION.
Judge the card on its own text. There is no query here and you do not know which search returned it — that is deliberate.

## Question

> what gets me value every time a land hits the battlefield?

**What makes it tricky:** Half these cards say 'Landfall' as a keyword and half spell out 'Whenever a land enters the battlefield under your control'; Azusa is the classic false friend since it enables land drops but has no trigger at all.

**Cards already accepted as satisfying it** (for a consistent reading, not as a pattern to match): Lotus Cobra, Tireless Tracker, Avenger of Zendikar

**Cards already rejected**: Azusa, Lost but Seeking

## Answer format

Write JSON to `verdicts/landfall-payoffs.json`: an object mapping each card name to `"present"`, `"absent"` or `"unclear"`.

- `present` — it clearly satisfies the question.
- `absent`  — it clearly does not.
- `unclear` — the question wording genuinely does not decide it. Use this freely; a forced call is worse than no call.

Every one of the cards listed must appear exactly once.
