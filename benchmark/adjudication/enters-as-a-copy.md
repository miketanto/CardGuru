# Adjudication: `enters-as-a-copy`

Decide, for each card below, whether it satisfies the QUESTION.
Judge the card on its own text. There is no query here and you do not know which search returned it — that is deliberate.

## Question

> creatures that come into play as a copy of something already on the battlefield

**What makes it tricky:** 'You may have ~ enter as a copy' is a copy-replacement applied as the permanent enters, distinct from an ETB trigger that creates a copy token; Clever Impersonator is actually a true positive, which is the trap in reverse.

**Author's notes:** [vetted by owner 2026-08-07] Clever Impersonator moved expect_absent -> expect_present. Clever Impersonator very likely belongs in expect_present (it enters as a copy of any nonland permanent). Vetter should move or delete it.

**Cards already accepted as satisfying it** (for a consistent reading, not as a pattern to match): Clone, Phyrexian Metamorph, Spark Double, Clever Impersonator

## Answer format

Write JSON to `verdicts/enters-as-a-copy.json`: an object mapping each card name to `"present"`, `"absent"` or `"unclear"`.

- `present` — it clearly satisfies the question.
- `absent`  — it clearly does not.
- `unclear` — the question wording genuinely does not decide it. Use this freely; a forced call is worse than no call.

Every one of the cards listed must appear exactly once.
