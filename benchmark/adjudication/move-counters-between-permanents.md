# Adjudication: `move-counters-between-permanents`

Decide, for each card below, whether it satisfies the QUESTION.
Judge the card on its own text. There is no query here and you do not know which search returned it — that is deliberate.

## Question

> anything that physically moves counters from one permanent to another

**What makes it tricky:** Moving a counter is neither adding nor removing, and cards express it as 'move a counter from', 'put those counters on', and 'remove a counter... put a counter on' - three shapes for one operation.

**Author's notes:** expect_absent lists a mechanic name, not a card - vetter should replace it with an actual proliferate card or empty the list. [vetting: dropped 'Proliferate' from expect_absent - a mechanic, not a card]

**Cards already accepted as satisfying it** (for a consistent reading, not as a pattern to match): Nesting Grounds, The Ozolith, Power Conduit

## Answer format

Write JSON to `verdicts/move-counters-between-permanents.json`: an object mapping each card name to `"present"`, `"absent"` or `"unclear"`.

- `present` — it clearly satisfies the question.
- `absent`  — it clearly does not.
- `unclear` — the question wording genuinely does not decide it. Use this freely; a forced call is worse than no call.

Every one of the cards listed must appear exactly once.
