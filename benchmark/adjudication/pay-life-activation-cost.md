# Adjudication: `pay-life-activation-cost`

Decide, for each card below, whether it satisfies the QUESTION.
Judge the card on its own text. There is no query here and you do not know which search returned it — that is deliberate.

## Question

> abilities where you pay life as part of the cost

**What makes it tricky:** 'Pay N life' as a cost reads nearly identically to 'you lose N life' in an effect; Bitterblossom loses life as part of a triggered effect, which is a different structure entirely.

**Author's notes:** Fetchlands are a large, boring chunk of the true answer set - vetter may want to scope this to nonland cards.

**Cards already accepted as satisfying it** (for a consistent reading, not as a pattern to match): Necropotence, Griselbrand, Bloodstained Mire

**Cards already rejected**: Bitterblossom

## Answer format

Write JSON to `verdicts/pay-life-activation-cost.json`: an object mapping each card name to `"present"`, `"absent"` or `"unclear"`.

- `present` — it clearly satisfies the question.
- `absent`  — it clearly does not.
- `unclear` — the question wording genuinely does not decide it. Use this freely; a forced call is worse than no call.

Every one of the cards listed must appear exactly once.
