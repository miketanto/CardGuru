## Question

> blink effects - exile my own creature and bring it right back

**What makes it tricky:** 'Blink' and 'flicker' appear on zero cards; the actual text is 'exile target creature, then return it to the battlefield', which shares its opening clause with real exile removal.

**Author's notes:** Return timing varies (immediately, end of turn, next end step) - vetter should decide whether all count.

**Cards already accepted as satisfying it** (for a consistent reading, not as a pattern to match): Cloudshift, Restoration Angel, Flickerwisp, Ephemerate

**Cards already rejected**: Swords to Plowshares

## Answer format

Write JSON to `verdicts/blink-effects.json`: an object mapping each card name to `"present"`, `"absent"` or `"unclear"`.

- `present` — it clearly satisfies the question.
- `absent`  — it clearly does not.
- `unclear` — the question wording genuinely does not decide it. Use this freely; a forced call is worse than no call.

Every one of the cards listed must appear exactly once.
