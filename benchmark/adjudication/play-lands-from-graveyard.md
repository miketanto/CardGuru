# Adjudication: `play-lands-from-graveyard`

Decide, for each card below, whether it satisfies the QUESTION.
Judge the card on its own text. There is no query here and you do not know which search returned it — that is deliberate.

## Question

> how do I replay lands from my graveyard

**What makes it tricky:** Extra-land-drop cards use nearly the same words ('you may play an additional land') but grant no graveyard permission at all.

**Cards already accepted as satisfying it** (for a consistent reading, not as a pattern to match): Crucible of Worlds, Ramunap Excavator

**Cards already rejected**: Azusa, Lost but Seeking, Exploration

## Answer format

Write JSON to `verdicts/play-lands-from-graveyard.json`: an object mapping each card name to `"present"`, `"absent"` or `"unclear"`.

- `present` — it clearly satisfies the question.
- `absent`  — it clearly does not.
- `unclear` — the question wording genuinely does not decide it. Use this freely; a forced call is worse than no call.

Every one of the cards listed must appear exactly once.
