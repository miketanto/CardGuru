# Adjudication: `cast-from-graveyard-permanents`

Decide, for each card below, whether it satisfies the QUESTION.
Judge the card on its own text. There is no query here and you do not know which search returned it — that is deliberate.

## Question

> permanents that let me cast spells straight out of my graveyard

**What makes it tricky:** This is a static casting permission that must be distinguished from self-recursion keywords (flashback, escape, disturb) and from cards like Snapcaster that grant flashback to one specific card.

**Cards already accepted as satisfying it** (for a consistent reading, not as a pattern to match): Muldrotha, the Gravetide, Lurrus of the Dream-Den, Underworld Breach

**Cards already rejected**: Snapcaster Mage

## Answer format

Write JSON to `verdicts/cast-from-graveyard-permanents.json`: an object mapping each card name to `"present"`, `"absent"` or `"unclear"`.

- `present` — it clearly satisfies the question.
- `absent`  — it clearly does not.
- `unclear` — the question wording genuinely does not decide it. Use this freely; a forced call is worse than no call.

Every one of the cards listed must appear exactly once.
