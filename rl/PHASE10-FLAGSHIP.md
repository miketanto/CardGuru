## 1. What this run is

Three lanes said the same thing from three directions, and this is the
run that does all of it at once:

- **7b** — optimistic Elo PFSP doubles the learning rate, but an ungated
  pool drifts (1101 → 1044 after the peak; the 9216 net loses .40 h2h to
  ck_6144). Its #1 recommendation was champion gating.
- **7c** — opponent-deck diversity beat every axis four phases had
  varied, reaching search parity in 1536 episodes.
- **8/8b** — E2 features are consumed as local identifiers because
  training was single-deck; deck diversity has to start from
  initialization, not from a fine-tune.

So: **from-scratch lstmattn, BPTT recurrent PPO, inside a champion-gated
PFSP league whose pool carries decks, with the agent's own deck drawn
from a widening rotation, on the Phase 9 fast path.**

## 3. Champion gating (the mechanism 7b asked for)

`league_lane_p7.sh`, `P10_GATE=1`. Every 512 episodes the frozen
snapshot plays **50 games head-to-head against the reigning champion**
on the mirror, sequentially (the gate decides pool membership, so it has
to be reproducible). Score counts a draw as half.

- score > .5 → the snapshot **enters `pool_elo.tsv`** and **becomes the
  reigning champion**. It enters at the champion's Elo plus the margin
  the h2h implies, `Δ = −400·log10(1/s − 1)`, capped at ±150.
- otherwise → nothing enters the pool. The league keeps training against
  a population it did not itself produce.

That is the whole fix for 7b's late drift: an ungated pool admits every
snapshot, so the optimism target ends up chasing a population that is
drifting with the agent. Note the noise: 50 games gives roughly ±.14 on
the score, so a single gate decision is not a rating claim — the gate is
a ratchet, not a measurement.

## 4. The pool

Rows are `name|kind|deck|elo` (the 7c schema), so a scripted seat
piloting an archetype deck sits in the same rated ladder as a served
snapshot. Deck rows are calibrated by `rl/p10_pool_calib.sh` before the
run: power *p* = win rate of D0 piloting the deck vs D0 piloting
BenchDimir over 100g, mapped to the D0=1000 anchor by
`Elo = 1000 + 400·log10(p/(1−p))`. Champion and snapshot rows keep their
Phase 6 mirror ratings, which are on that same anchor.
